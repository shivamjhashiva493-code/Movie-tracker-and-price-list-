ZIP डाउनलोड के बाद क्या करना है (Step-by-Step Guide)

1 ZIP फाइल डाउनलोड और अनजिप करें

ऊपर दिए गए हरे बटन से Download .ZIP करें। उस ज़िप फाइल पर राइट क्लिक करके Extract Here करें। आपको 4 फाइलें मिल जाएंगी।

2 GitHub.com पर नई Repository बनाएँ

github.com पर लॉगिन करें। New Repository दबाएं, नाम रखें (उदा: cinema-price-tracker) और Public रखकर Create करें।

3 फाइलें अपलोड (Upload) करें

रिपॉजिटरी में Upload files पर क्लिक करके अनजिप किए गए फोल्डर की सभी फाइलों (index.html, scraper.py, .github फोल्डर और README.md) को ड्रैग करके अपलोड करें और Commit Changes दबाएँ।

4 GitHub Pages ऑन करें (वेबसाइट लाइव!)

रिपॉजिटरी के Settings ➔ Pages में जाएं। Branch में main चुनकर Save करें। 1 मिनट में आपकी वेबसाइट का फ्री लिंक (जैसे: https://your-name.github.io/cinema-price-tracker) चालू हो जाएगा!

✅ ऑटो-अपडेट: GitHub Actions अपने-आप हर रोज़ सुबह 6:00 बजे और दोपहर 12:00 बजे scraper.py चलाकर टिकट के नए दाम वेबसाइट पर खुद ब खुद अपडेट करता रहेगा।
